## Hello

I am Nick Walker. I design and build software in Australia.

Most of what I build is data tooling. Some of it are personal and educational projects, games and puzzles.

### What is here

**[DataCrafter](https://www.datacrafter.net)** - a comprehensive data engineering platform. Releases are public, the source is private.

**[DataCrafter Releases Repo](https://github.com/nick2468/DataCrafter-releases)** - To open-source, or not to open-source, that is the question.

**[Conquest](https://github.com/nick2468/Conquest)** - a turn-based territory
game for the iPad and the web. Three hand-drawn maps, eight computer
opponents, and it plays with the network off. The rules engine touches no
browser, no clock and no hidden random numbers, so the same code runs in the
game, in the tests, in a self-play tuner and on a server.
[Play it](https://conquest.datacrafter.net).

**[Tabiya](https://github.com/nick2468/Tabiya)** - a desktop trainer for chess
opening repertoires. Ten courses: study a line and why each move is played,
drill it back from memory on a schedule, then play it against an engine
steered into the lines you have studied. Every line the notes name is played
on a board by a checker, which is how a note that recommends an illegal move
gets caught before a reader trusts it.
[Download it](https://github.com/nick2468/Tabiya/releases/latest).

**[jcc](https://github.com/nick2468/jcc)** - a small C compiler written in
Java.

### About the downloads

My installers are not signed with a code signing certificate, so Windows will
warn you that the publisher is unknown and ask whether you want to continue.
That prompt is expected and says nothing about the file beyond the fact that I
have not bought a certificate. Where the source is public you are welcome to
read it, or build it yourself, rather than take my word for it.
