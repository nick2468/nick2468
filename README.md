## Hello

I am Nick Walker. I design and build software in Australia.

Most of what I build is data tooling. Some of it are personal and educational projects, games and puzzles.

### What is here

**[DataCrafter](https://datacrafter.net)** - a comprehensive data engineering platform. Releases are public, the source is private.

**[DataCrafter Releases Repo](https://github.com/nick2468/DataCrafter-releases)** - To open-source, or not to open-source, that is the question.

**[Conquest](https://github.com/nick2468/Conquest)** - a turn-based territory
game for the iPad and the web. Three hand-drawn maps, eight computer
opponents, and it plays with the network off. The rules engine touches no
browser, no clock and no hidden random numbers, so the same code runs in the
game, in the tests, in a self-play tuner and on a server.
[Play it](https://conquest.datacrafter.net).

**[jcc](https://github.com/nick2468/jcc)** - a small C compiler written in
Java.
